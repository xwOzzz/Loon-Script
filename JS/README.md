# JS — 第三方脚本配置合集

本目录收集各类第三方作者编写的 Loon 脚本配置（.conf），以作者名命名，方便按需添加订阅使用。

## 使用方法

1. 在 Loon 中进入 **配置 → 订阅 → 脚本 → 添加订阅**，填入对应配置文件的 raw 链接。
2. 按文件内注释的步骤获取 Cookie（一般是打开对应 App 触发一次请求）。
3. **获取完 Cookie 后，记得把 Cookie 获取部分禁用或删除**，只保留定时任务，避免重复抓包。
