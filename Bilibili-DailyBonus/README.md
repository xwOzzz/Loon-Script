# Bilibili-DailyBonus — 哔哩哔哩漫画每日奖励

本目录收集哔哩哔哩漫画的每日奖励脚本（.js），均整理自 NobyDa 的公开脚本：一个负责每日签到，一个负责积分商城抢购，两者共用同一份漫画 Cookie（CookieBM），需先签到脚本获取 Cookie 后方可使用抢购脚本。

## 使用方法

1. 在 Loon 中按各脚本文件头的配置添加定时任务（签到脚本另需一条 http-request 规则抓取 Cookie，MITM 主机名为 app.bilibili.com）。
2. 打开哔哩哔哩漫画 App（App Store 中国区），点「我的」，收到获取 Cookie 成功的通知后，签到脚本即可在每天上午 9 点自动执行。
3. 抢购脚本默认在中午 12:00:10、12:00:20、12:00:30 执行，默认兑换积分商城中的「积分兑换」，数量为用户积分可兑换的最大值；商品名、数量与循环抢购次数可在 BoxJs 内修改。
